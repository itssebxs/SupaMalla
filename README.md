# SupaMalla - Gestión Académica

> ⚠️ **Aviso Importante:** Este proyecto se encuentra actualmente **descontinuado**. [cite_start]Aunque SupaMalla fue concebida y desarrollada como una aplicación móvil[cite: 47], el código fuente alojado en este repositorio de GitHub corresponde **únicamente a la parte web** del proyecto.

## 📖 Sobre el Proyecto

[cite_start]SupaMalla es una herramienta diseñada para facilitar la gestión y la planificación académica[cite: 46, 47]. El proyecto nació con el propósito de ofrecer a los estudiantes una forma más intuitiva de organizar su trayectoria estudiantil.

## ✨ Características Principales

* [cite_start]**Planificación visual:** Visualización interactiva de mallas curriculares para una mejor comprensión de la ruta de estudio[cite: 48].
* [cite_start]**Monitoreo estudiantil:** Sistema de seguimiento de progreso para mantener al día los objetivos académicos[cite: 49].
* [cite_start]**Gestión de información:** Estructuración de base de datos diseñada específicamente para la gestión académica[cite: 50].
